# ElevAmp intake systems concept

An unofficial, independent homepage prototype showing how legal intake systems and CRM operations can connect marketing activity to signed matters.

## What is included

- Responsive, static homepage
- Interactive unmanaged/designed intake journey
- Seven-question private intake diagnostic
- People → Process → Technology framework
- Map → Define → Assign → Measure audit model
- Purposeful handoff animation
- Reduced-motion and keyboard support
- No backend, analytics, cookies, or data submission

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Deployment

The site is plain HTML, CSS, and JavaScript and can be deployed to GitHub Pages or any static host without a build step.
